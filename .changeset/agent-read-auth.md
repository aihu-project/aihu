Require host authorization before serving agent state reads, resolve tenant actors from live host lookups, recursively project JSON-safe results, and bind browser bridge sessions to one-use connection nonces with per-invocation reauthorization. Migration: bridge clients must speak protocol v2 and send `nonce`, `sessionToken`, `sessionIdentity`, and the verified `grantVersion` in `hello`; hosts must return `{ identity, grantVersion? }` from both `verifyBridgeSession` and `reauthorizeBridgeInvoke`, and supply `actorResolver` and `authorizeDataRead` for protected state reads. `securityHookTimeoutMs` and `bridgeCallTimeoutMs` configure bounded hook/call waits (5000ms defaults). Hosts may call `server.revokeBridgeSession(identity, grantVersion?)` to cancel matching in-flight calls. A revoked state read returns a denial without its result. A forwarded action may already have run when its result is denied or authorization times out; in that case the server returns `BRIDGE_RESULT_WITHHELD` and callers must treat the action outcome as unknown. Projected leaves must be JSON-safe primitives, arrays, and plain records; functions, symbols, bigints, non-finite numbers, non-plain objects such as `Date`, and objects with callable `toJSON` hooks now fail closed as `CAPABILITY_UNAVAILABLE`.
